# Sales Project

## 1. Project Overview
This project uses Microsoft Excel to analyze sales data and create an interactive sales dashboard. It helps users understand sales performance by product,
region, and salesperson.

## 2. Workbook Sheets
- **Raw Data:** Contains the original sales records and the Sales Category formula.
- **Sales Analysis:** Contains PivotTables, a PivotChart, Slicers, and a Timeline.
- **Documentation:** Contains project details, formulas, and analysis methods.

## 3. Data Cleaning
The dataset was checked for duplicate records and blank cells to improve data quality.

## 4. Excel Formulas Used
- **IF:** Categorizes sales as High or Low based on a sales threshold.
- **VLOOKUP:** Retrieves product information using an Order ID.
- **INDEX-MATCH:** Retrieves product price information using an Order ID.

## 5. Data Analysis
PivotTables were created to summarize sales by product and region.

## 6. Data Visualization
A PivotChart was created to visualize product-wise sales. Conditional Formatting was used to highlight sales values.

## 7. Interactive Dashboard
Slicers and a Timeline were added to help users filter sales data by available categories and dates.

## 8. How to Use the Workbook
1. Open the Excel workbook.
2. Select the Sales Analysis sheet to view the PivotTables and chart.
3. Use the Slicers and Timeline to filter the data.
4. Open the Raw Data sheet to view the source records and formulas.
5. Open the Documentation sheet to read the project summary.

## 9. Conclusion
This Excel dashboard provides a convenient way to explore sales data, compare product and regional performance, and understand sales trends.
